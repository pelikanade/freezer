# Agent instructions

## Project map

`.project-map/index.html` is the owner's local status board: milestones, parts, stuck items, the next step, and decisions the owner must make. It is gitignored; do not commit it unless the owner asks.

- Before a long solo stretch (overnight, multi-hour, multi-session), refresh `.project-map/` (`project-map` skill).
- After each milestone lands, update `.project-map/`.
- When asked "where are we?" or for status, answer from `.project-map/`, not from chat memory.
